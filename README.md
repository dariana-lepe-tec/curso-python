# Fundamentos de programación


**Alumno:** Dariana Lepe


Repositorio de las actividades del curso Fundamentos de programación (Universidad Tecmilenio).

La carpeta semana1 contiene la Actividad 1 "Mi rutina digital": algoritmo, diagrama de flujo, notebook en Python y la Parte E.

La carpeta semana2 contiene la Actividad 2 "La taquilla del museo": tabla de decisión, diagrama de flujo, programa en Python y casos de prueba.

La carpeta semana3 contiene la Actividad 3, avance del proyecto (Fase I): análisis de la taquilla de Cinépolis Esfera, pseudocódigo y diagrama de flujo en PSeInt, prototipo en Python y práctica de integración.

La carpeta semana4 contiene la Actividad de la tabla de Pitágoras: matriz de 10 x 10 con ciclos for anidados, una función que imprime la tabla, una función que consulta productos y casos de prueba.

La carpeta semana5 contiene la Actividad 4, menú modular: un programa con menú que llama a una función por sección (tuplas, diccionarios, excepciones y strings), con la evidencia de ejecución de las pruebas.
